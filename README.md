# ABYDOS PAPER DRESSER

브라우저에서 실행하는 종이인형식 파츠 조합 편집기입니다.

## 실행
- `index.html`을 브라우저에서 열어 개인용으로 사용할 수 있습니다.
- GitHub Pages로 공개할 때는 저장소 루트에 `index.html`, `data/default-project.json`을 함께 올립니다.

## 학생과 파츠 추가
1. 화면 왼쪽에서 학생 이름을 입력하고 **학생 추가**를 누릅니다.
2. 오른쪽에서 카테고리와 원본 학생을 선택합니다.
3. 투명 PNG 파츠를 등록합니다.
4. 베이스와 표정은 원본 학생 전용이며, 헤어·의상·신발·장신구는 공용으로 장착할 수 있습니다.

## GitHub에 기본 라이브러리 공유하기
1. 편집기에서 학생과 파츠를 등록합니다.
2. **GitHub 기본 데이터 내보내기**를 눌러 `default-project.json`을 받습니다.
3. 이 파일을 저장소의 `data/default-project.json`에 덮어씁니다.
4. `index.html`과 JSON 파일을 함께 커밋/푸시합니다.
5. GitHub Pages를 활성화합니다.

처음 방문한 브라우저는 `data/default-project.json`을 불러옵니다. 이후 그 브라우저에서 수정한 내용은 해당 브라우저의 IndexedDB에 별도로 저장됩니다. 기존 로컬 데이터가 기본 데이터보다 우선합니다.

## 백업과 개인정보
- **개인 백업**은 현재 작업 데이터를 JSON으로 내보냅니다.
- **GitHub 기본 데이터 내보내기**는 공개 배포용 기본 라이브러리 JSON을 내보냅니다.
- JSON에는 이미지가 Base64로 포함되므로 파일 크기가 커질 수 있습니다.
- 공개 저장소에 올리는 이미지의 저작권과 이용 허락을 확인하세요.
